# SERRA reproducibility repository

This repository accompanies the manuscript:

**SERRA: A Stochastic Framework for Plant Biomass Growth Combining Itô–Lévy Analysis and Numerical Evaluation on Irrigated Rice**

## Authors
Mohamed BADJI; Omar Ndaw FAYE; Mamadou CISS; El Hadji DEME; Mamadou NDIAYE.

## Purpose
The repository is intended to provide the computational materials needed to reproduce the SERRA numerical workflow, including calibration, Monte Carlo simulation, predictive uncertainty analysis, and Sobol global sensitivity analysis.

## Data availability
Daily meteorological forcing is derived from the publicly available NASA POWER database.

The experimental biomass and leaf area index (LAI) observations used for calibration and evaluation are **not included** in this repository. Their dissemination is subject to authorization by the institutions involved in the experimental data collection.

No individual experimental measurements are distributed here.

## Repository structure
- `code/` — SERRA implementation and analysis scripts.
- `data/` — documentation for data inputs; no restricted experimental observations.
- `parameters/` — published parameter values and sensitivity-analysis ranges.
- `results_reproduction/` — instructions and outputs for reproducing reported analyses.

## Reproducibility status
The repository structure and non-restricted parameter files are prepared. The executable source scripts will be added from the authors' original analysis code before the archival release.
